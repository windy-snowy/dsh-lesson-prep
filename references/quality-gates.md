# 判据与下载页规格

`scripts/verify_pack.py` 把本文的判据变成可执行检查。`fail` 表示交付物不合格，必须修；
`warn` 表示还差内容或场景限制，必须如实告诉用户。

---

## 一、九条交付判据

| 产出 | 判据 | 检查方式 |
| --- | --- | --- |
| 课程方案 | 含讲解 / 提问 / 讨论 / 代码 / 视频五类活动；时段合计 = 课时；末段留 5 分钟练习且不写题目；**连续散文，无表格、无分条**；每段有「老师讲什么 / 学生做什么」 | 脚本查表格与分条正则、时间盒合计；人工看叙述质量 |
| 精简课件 | 页数 = 原页数 − 删除数；保留率 65%–75%；封面 / 资源页 / 分隔页 / 小结页 / 每节首页未删；无空白页 | 脚本查 `plan.json` 自洽性与 PPTX 空白页 |
| 原理图页 | 每页一个知识点，图为流程图或原理示意图；主色与原课件一致；中文无错字乱码；图片版与元素版都能打开 | `slide-forge qa` + 人工确认总览图 |
| 视频 | 至少 1 条 ≤5 分钟；清单含标题 / UP 主 / BV 号 / 时长 / 链接 / 推荐理由 / 课堂用法；下载脚本可执行；MP4 为 H.264 + AAC | 脚本查清单要素；`ffprobe` 查编码 |
| 讨论题 | 背景 / 分组 / 时间盒 / 参考解 / 评分标准齐备；参考解能落到"改造清单 + 翻车点" | 脚本查关键字；人工看参考解深度 |
| 单选题 | 恰好 10 题、每题 4 选项、唯一正确答案、解析非空 | 脚本逐题结构化检查 |
| 演示代码 | 两个 `.py`；CPU 上数十秒跑完并出图；有中文注释与可视化 | 脚本查数量 / 中文 / 可视化；实际运行一次 |
| 数据集图 | 至少 1 张带类别标注的真实样本图；注明来源与许可 | 脚本查文件名与存在性；人工看图 |
| 打包 | zip 可解压、中文文件名不乱码；`index.html` 每条相对链接可打开 | 脚本解压并逐链接试开 |

## 二、时间盒规格（默认 90 分钟）

| 时段 | 分钟 | 性质 |
| --- | --- | --- |
| 开场与回顾 | 5 | 固定 |
| PPT 讲解 | 38 | 变量：由页面预算反推 |
| 课堂提问 | 7 | 固定（3–4 次插入式 + 1 次小结） |
| 代码演示 | 18 | 固定（两个 demo，各 9 分钟） |
| 视频演示 | 6 | 固定（≤5 分钟片段 + 解读） |
| 课堂讨论 | 10 | 固定 |
| 练习 | 5 | 固定，**只留时间不写题目** |
| 收尾总结 | 1 | 固定 |
| **合计** | **90** | 断言：合计 == `--minutes` |

课时不足 90 分钟时按比例压缩提问 / 代码 / 视频 / 讨论，练习仍固定 5 分钟；
课时少于 60 分钟时给「平均每页时长偏低」的 warning。

## 三、删页规格

**硬保护（永不删）**：前 3 页、小结页、所有分隔页、每个小节前 2 页。

**删除优先级**：重复页 → 整页代码 → 运行结果截图 → 内容偏薄页 → 以截图为主页。

**保留率**：默认 70%，钳制在 65%–75%。越界写 warning，不静默通过。

**教师覆盖**：`--drop 7 13 20` 指定必删页；想保某页就从 `plan.json` 的
`delete_list.delete_pages` 里去掉该页号再跑 `trim`。

## 四、下载页（`index.html`）规格

`bundle` 生成一个**自包含目录**，布局固定：

```
<out>/
├── index.html                 下载页（本文件）
├── <name>.zip                 整包
└── <pack_name>/               解压后的全部文件（下载页逐文件下载的目标）
```

页面要求：

- 纯静态 HTML + 内联 CSS，不引任何外部资源（离线可用）；
- 顶部有**整包下载按钮**，`href` 指向同目录下的 zip，带 `download` 属性；
- 下方是逐文件表格（文件名 + 大小），链接指向 `<pack_name>/<相对路径>`；
- 文件名与链接都要 URL 编码，中文才能正确打开；
- 页脚注明"视频与图片版权归原作者，仅供课堂教学使用"。

**为什么必须保持这个布局**：下载页用的是**相对链接**，zip 与文件目录必须与 `index.html` 同级或在其下，
否则链接全断。`bundle` 会自动把 `--pack-dir` 复制成 `<out>/<pack_name>/`，所以直接跑命令即可。

**分享方式**：

```bash
cd <out> && python3 -m http.server 8010 --bind 0.0.0.0
# 浏览器打开 http://<host>:8010/
```

## 五、验收命令

```bash
python3 scripts/verify_pack.py --pack-dir ./runs/rnn-90          # 人读格式
python3 scripts/verify_pack.py --pack-dir ./runs/rnn-90 --json   # 机器读格式
```

退出码：0 = 无 fail；1 = 有 fail。`warn` 不影响退出码，但必须在汇报里列出。
